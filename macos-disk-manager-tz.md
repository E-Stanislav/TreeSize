# Техническое задание: macOS Disk Manager

## 1. Общие сведения

### 1.1. Наименование проекта
**macOS Disk Manager** — приложение для анализа дискового пространства, управления файлами и удаления программ на macOS.

### 1.2. Назначение приложения
Приложение предназначено для упрощения работы с файловой системой macOS: визуализация占用 дискового пространства, поиск больших файлов, удаление приложений с остаточными файлами, мониторинг использования памяти.

### 1.3. Целевая аудитория
- Пользователи macOS, желающие освободить место на диске
- Технические специалисты, нуждающиеся в детальном анализе файловой системы
- Пользователи, желающие корректно удалять приложения

## 2. Функциональные требования

### 2.1. Анализ дискового пространства

#### 2.1.1. Сканирование дисков
- Сканирование всех подключённых накопителей (внутренние SSD/HDD, внешние диски, флешки, сетевые тома)
- Поддержка APFS, HFS+, exFAT, FAT32
- Отображение свободного/занятого места в реальном времени
- Прогресс-бар сканирования с возможностью паузы

#### 2.1.2. Визуализация
- **Treemap (древовидная карта)** — прямоугольники пропорциональны размеру файлов/папок
- **Sunburst diagram (круговая диаграмма)** — иерархическое представление структуры папок
- **Icicle chart** — альтернативная иерархическая визуализация
- Цветовое кодирование по типам файлов (документы, медиа, приложения, кэш и т.д.)
- Интерактивность: клик по элементу для перехода в папку, drill-down навигация

#### 2.1.3. Отчёты и статистика
- Топ-100 самых больших файлов
- Топ-100 самых старых файлов (по дате изменения)
- Группировка по типам файлов с процентным соотношением
- Группировка по папкам с отображением размера
- Фильтрация по дате (за последний день/неделю/месяц/год)
- Экспорт отчёта в CSV/JSON/Markdown

### 2.2. Управление файлами

#### 2.2.1. Базовые операции
- Удаление файлов и папок (с перемещением в корзину)
- Перемещение файлов между дисками/папками
- Копирование файлов
- Переименование
- Пакетное выделение и операции

#### 2.2.2. Поиск дубликатов
- Сканирование на точные копии файлов (по хешу)
- Группировка дубликатов с предпросмотром
- Расчёт экономии места при удалении
- Безопасное удаление с подтверждением

#### 2.2.3. Очистка системного мусора
- Кэш приложений (~/Library/Caches, /Library/Caches)
- Логи системы и приложений
- Временные файлы (/tmp, ~/tmp)
- Корзина (с возможностью выборочного удаления)
- Кэш браузеров (Safari, Chrome, Firefox)
- Старые резервные копии iOS/iPadOS
- Purgeable space (оптимизированное хранилище macOS)

#### 2.2.4. Работа с большими файлами
- Быстрый список файлов >100 МБ, >500 МБ, >1 ГБ
- Сортировка по размеру, дате, типу
- Предпросмотр без открытия в Finder

### 2.3. Управление приложениями (Uninstaller)

#### 2.3.1. Список установленных приложений
- Отображение всех приложений в /Applications, ~/Applications, /Library/Application Support
- Размер каждого приложения (основной бандл + остаточные файлы)
- Дата установки, дата последнего запуска
- Иконка приложения

#### 2.3.2. Удаление приложений
- Полное удаление: основной бандл + связанные файлы
- Поиск остаточных файлов в:
  - ~/Library/Application Support/
  - ~/Library/Caches/
  - ~/Library/Preferences/
  - ~/Library/Logs/
  - ~/Library/Containers/
  - ~/Library/Saved Application State/
  - /Library/LaunchAgents/, /Library/LaunchDaemons/
- Подтверждение перед удалением с списком файлов
- Отмена удаления до перемещения в корзину

#### 2.3.3. Системные приложения
- Предупреждение при попытке удаления системных приложений macOS
- Блокировка удаления критических системных компонентов

### 2.4. Мониторинг памяти (RAM)

#### 2.4.1. Использование оперативной памяти
- Общее использование RAM (активная, сжатая, кэш, свободная)
- Топ процессов по потреблению памяти
- Графики в реальном времени (линейный, gauge)
- Виджет в меню-баре с быстрым доступом

#### 2.4.2. Управление памятью
- Принудительное завершение процессов
- Очистка кэша памяти (purge)
- Рекомендации по оптимизации

### 2.5. Дополнительные функции

#### 2.5.1. Снимки состояния (Snapshots)
- Сохранение текущего состояния диска
- Сравнение двух снимков (что выросло/уменьшилось/появилось/удалено)
- Экспорт различий в CSV/JSON/Markdown
- История снимков с датами

#### 2.5.2. Планировщик очистки
- Автоматическая очистка по расписанию (ежедневно/еженедельно/ежемесячно)
- Выбор категорий для автоматической очистки
- Уведомления перед очисткой

#### 2.5.3. Интеграция с macOS
- Виджет в меню-баре с быстрым доступом
- Уведомления macOS при критическом уровне свободного места (<10%, <5%)
- Shortcuts.app поддержка (автоматизация через Apple Shortcuts)
- Контекстное меню в Finder (анализировать папку)

## 3. Технические требования

### 3.1. Платформа и совместимость
- **ОС:** macOS 12.0 (Monterey) и выше
- **Архитектура:** Universal Binary (Intel + Apple Silicon)
- **Язык:** Swift 5.9+
- **UI Framework:** SwiftUI + AppKit (для совместимости)

### 3.2. Производительность
- Сканирование диска 500 ГБ: ≤60 секунд
- Потребление RAM при сканировании: ≤500 МБ
- Запуск приложения: ≤2 секунд
- Плавность UI: 60 FPS при навигации по treemap

### 3.3. Безопасность
- Sandboxing с необходимыми entitlements:
  - `com.apple.security.files.user-selected.read-write`
  - `com.apple.security.files.downloads.read-write`
  - `com.apple.security.files.bookmarks.app-scope`
  - `com.apple.security.temporary-exception.files.trash`
- Запрос Full Disk Access при первом запуске (для сканирования системных папок)
- notarization через Apple Developer ID
- Отсутствие сбора персональных данных

### 3.4. Локализация
- Русский язык (основной)
- Английский язык
- Поддержка системных настроек языка macOS

### 3.5. Архитектура приложения

```
┌─────────────────────────────────────────┐
│              UI Layer (SwiftUI)         │
│  - Views: DiskMap, FileList, Uninstaller│
│  - ViewModels: ScannerVM, CleanupVM     │
└─────────────────────────────────────────┘
                    │
┌─────────────────────────────────────────┐
│         Business Logic Layer            │
│  - DiskScanner (FileManager, attributes)│
│  - DuplicateFinder (SHA256 hashing)     │
│  - AppUninstaller (bundle + leftovers)  │
│  - MemoryMonitor (sysctl, task_info)    │
└─────────────────────────────────────────┘
                    │
┌─────────────────────────────────────────┐
│            Data Access Layer            │
│  - Core Data / SQLite (snapshots)       │
│  - UserDefaults (настройки)             │
│  - Keychain (если нужна авторизация)    │
└─────────────────────────────────────────┘
```

### 3.6. Зависимости
- **Swift Package Manager** для управления зависимостями
- **Charts** (Apple) — для графиков использования памяти
- **SwiftSyntax** (опционально) — для парсинга plist
- Собственная реализация treemap/sunburst (Core Graphics / Metal)

## 5. Сценарии использования (User Stories)

### US-1: Освобождение места на диске
> **Как** пользователь с заполненным диском  
> **Я хочу** быстро найти самые большие файлы  
> **Чтобы** удалить их и освободить место

**Acceptance Criteria:**
- Приложение сканирует диск за ≤60 секунд
- Отображает топ-100 файлов по размеру
- Позволяет удалить файл в один клик
- Показывает освобождённое место после удаления

### US-2: Удаление приложения без следов
> **Как** пользователь  
> **Я хочу** удалить приложение со всеми остаточными файлами  
> **Чтобы** не засорять систему

**Acceptance Criteria:**
- Показывает список всех связанных файлов
- Предупреждает перед удалением
- Удаляет бандл + leftovers в корзину
- Не удаляет системные приложения без предупреждения

### US-3: Поиск дубликатов фото
> **Как** пользователь с большой библиотекой фото  
> **Я хочу** найти точные копии файлов  
> **Чтобы** удалить лишние и сэкономить место

**Acceptance Criteria:**
- Сканирует выбранные папки на дубликаты
- Группирует копии с предпросмотром
- Показывает экономию при удалении
- Удаляет только выбранные пользователем копии

### US-4: Мониторинг памяти в реальном времени
> **Как** разработчик  
> **Я хочу** видеть использование RAM в меню-баре  
> **Чтобы** быстро выявлять прожорливые процессы

**Acceptance Criteria:**
- Виджет показывает % использования RAM
- Клик открывает детальную таблицу процессов
- Данные обновляются каждые 2-5 секунд
- Можно завершить процесс из приложения

### US-5: Сравнение состояния диска
> **Как** пользователь  
> **Я хочу** сравнить диск до и после очистки  
> **Чтобы** понять, что именно освободилось

**Acceptance Criteria:**
- Сохранение снимка состояния в один клик
- Выбор двух снимков для сравнения
- Таблица с колонками: путь, было, стало, разница
- Экспорт отчёта в CSV/Markdown

### 6.1. Надёжность
- Отсутствие падений при сканировании битых секторов
- Обработка ошибок прав доступа (permission denied)

- Интуитивный интерфейс без обучения

### 6.3. Производительность
- Многопоточное сканирование (GCD / Swift Concurrency)
- Ленивая загрузка элементов treemap
- Кэширование результатов сканирования
- Фоновая очистка без блокировки UI

### 6.4. Масштабируемость
- Поддержка дисков до 10 ТБ
- Корректная работа с миллионами файлов
- Оптимизация под Apple Silicon (Metal для рендеринга)
